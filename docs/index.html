Install

Ready in under a minute

You need Claude Code, Git and Node.js 18 or newer. It adds one /card command and nothing else.

  1. Clone it into your skills folder

    Run this in PowerShell, bash or zsh.

    git clone --depth 1 https://github.com/CodySpooner/claude-card "$HOME/.claude/skills/card"

  2. Start a new Claude Code session

    Claude Code picks up new skills when a session starts. This works in the terminal and in the desktop app's Code tab.

  3. Type /card

    Your card opens in your browser. On a long history it can take about a minute. To print a handle instead of your account name, run /card Ada Lovelace.

Update or uninstall

To update:

git -C "$HOME/.claude/skills/card" pull

To uninstall, delete the ~/.claude/skills/card folder. Your saved card is in ~/.claude/claude-card, so delete that folder too if you don't want it.

Privacy

Your stats stay yours

Everything runs locally

A small script counts your local transcripts and writes one HTML file on your machine. Nothing is uploaded, and nothing leaves unless you post it.

Only numbers and a name

The card holds your display name and the numbers you see. Never your email, your prompts or anything you wrote.

One outside request

The card page loads its fonts from Google Fonts, so Google sees that request, but not your stats.
